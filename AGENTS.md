Use uv to run python script : `uv run myscript.py`

Ingest the document requested by the user to extend the helium wiki:
* Apply the analyze agent to the document to identify the optimization guidelines contained in the document
* For each document extract returned by the agent, apply the extractor agent that will generate wiki pages
* For each generated page, apply the validation python scripts/validate.py 
* The script is called with `uv run validate.py <path to wiki file> <path to output error file>` 
  The error output file is a markdown file generated by the script and describing in detail the errors
* stop if no error is returned
* If an error is returned, give the path to the error file to the correction agent and validate again the file once the agent has applied the corrections
* Continue corrections until until there is no more any validation error
* Once all new pages have been corrected, launch the concept agent to update the wiki concept map
* Then regenerate the queries and the aliases using scripts/gen_query.py and scripts/gen_aliases.py

# Rules to respect
* For helium code examples, use https://github.com/ARM-software/CMSIS-DSP and don't use the older CMSIS_5 that may still be referenced in old documentation.
* Don't leave, in the generated wiki pages, references to local documents that won't be available to the user of the skill.  Only references acceptable are URL and names of official public documents.

* The markdown MUST NOT contain any customer or partner proprietary information.

* The markdown MUST NOT contains any benchmark data (like cycles).
